# Psicommunity

Conectando pessoas ao cuidado psicológico e aproximando estudantes da prática profissional.

O Psicommunity é um projeto acadêmico que propõe uma plataforma digital para facilitar o acesso ao atendimento psicológico e criar oportunidades de aproximação entre estudantes de Psicologia e a prática profissional.

A iniciativa parte de um desafio social: muitas pessoas encontram dificuldades para conseguir atendimento psicológico, seja por limitações financeiras, barreiras de acesso aos serviços públicos ou demora no atendimento. Ao mesmo tempo, estudantes em formação precisam de oportunidades para desenvolver suas habilidades e aproximar os conhecimentos acadêmicos da realidade profissional.

O projeto busca unir essas duas necessidades em uma única solução.

**Objetivos do projeto**

- Ampliar o acesso à assistência psicológica: propor uma alternativa que facilite a aproximação entre pessoas que necessitam de atendimento e profissionais da área.
- Apoiar a formação acadêmica: criar oportunidades para que estudantes de Psicologia tenham contato com experiências práticas, sob a devida orientação profissional.
- Promover inclusão social: considerar diferentes realidades e facilitar o acesso aos serviços por meio de recursos digitais.
- Explorar novas possibilidades de atendimento: contemplar a proposta de atendimentos presenciais e online.

**Funcionalidades e proposta**

O Psicommunity foi concebido para reunir recursos relacionados à comunidade de Psicologia, considerando diferentes perfis de usuários e suas necessidades.

Entre as funcionalidades previstas na proposta estão:

- Cadastro e acesso de usuários.
- Diferenciação de perfis e possibilidades de interação.
- Aproximação entre pessoas que buscam atendimento e integrantes da comunidade de Psicologia.
- Possibilidade de escolha entre atendimento presencial e online.
- Organização e agendamento de atendimentos.

Nota: o projeto encontra-se em fase de prototipação acadêmica. As funcionalidades disponíveis na versão atual podem diferir da proposta completa.

Armazenamento de dados

Nesta versão, o projeto utiliza um mecanismo de armazenamento local no próprio ambiente do site, sem integração com um servidor ou banco de dados remoto.

Por se tratar de um protótipo, os dados inseridos durante a utilização não possuem persistência entre novas aberturas da aplicação. Ao fechar e reabrir a página, as informações cadastradas durante os testes podem ser perdidas.

Essa limitação é conhecida e faz parte do estágio atual de desenvolvimento.

Como executar o projeto

1. Clone o repositório:
   
   git clone URL_DO_REPOSITORIO

2. Acesse a pasta do projeto:
   
   cd Psicommunity

3. Abra o arquivo "index.html" em um navegador.
   
   Para uma experiência de desenvolvimento mais prática, recomenda-se utilizar o Visual Studio Code com a extensão Live Server.

Próximas etapas

Entre as possibilidades de evolução do projeto estão:

- Implementação de um banco de dados persistente.
- Desenvolvimento de uma API para integração entre interface e servidor.
- Aprimoramento dos mecanismos de autenticação e gerenciamento de usuários.
- Implementação de fluxos completos de agendamento.
- Evolução dos recursos de comunicação e interação entre usuários.
- Aprimoramento de segurança, acessibilidade e responsividade.

Contexto acadêmico

O Psicommunity foi desenvolvido como projeto acadêmico, com o objetivo de aplicar conhecimentos de desenvolvimento de sistemas na construção de uma solução voltada a uma necessidade social.

Além dos aspectos técnicos, o projeto busca explorar como a tecnologia pode contribuir para a democratização do acesso à saúde psicológica e para a formação de futuros profissionais.
